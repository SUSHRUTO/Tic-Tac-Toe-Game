# ✏️ Old School Notebook Tic Tac Toe

A unique Tic Tac Toe game built with **React**, **Vite**, and **Tailwind CSS** that recreates the nostalgic feeling of students playing Tic Tac Toe in school notebooks.

Unlike traditional neon or gaming-style Tic Tac Toe projects, this project provides an **old-school classroom experience** with a notebook-themed interface, handwritten styling, and interactive gameplay.

## 📖 Project Overview

This project transforms the classic Tic Tac Toe game into a nostalgic school notebook experience.

Players enter their names before starting the game and compete in a notebook-style environment with handwritten visuals, notebook margins, and a pen-style winning line.

---

## ✨ Features

### 🎮 Gameplay

- 3×3 Tic Tac Toe board
- Two-player turn system
- Player name input before starting
- Dynamic turn display using player names
- Winner detection
- Draw detection
- Reset game functionality
- New players option

---

### 📒 Old School Notebook Experience

- Notebook paper themed UI
- Blue notebook lines
- Red notebook margin line
- Handwritten style elements
- Pen-colored X and O marks
- Highlighted winning cells
- Winning line drawn like students do in notebooks
- Name / Class / Date section

## ⚙️ Installation & Setup

Clone repository:

```bash
git clone https://github.com/SUSHRUTO/Tic-Tac-Toe-Game
```

Navigate to project folder:

```bash

```

Install dependencies:



## 🎯 How To Play

1. Enter both player names
2. Click **Start Tic Tac Toe Match**
3. Players take turns placing X and O
4. First player to align 3 symbols wins
5. If all cells are filled without a winner, the match ends in a draw
6. Use:

- **🧽 Erase & Start Again** → Restart with same players
- **👥 New Players** → Start with different players
